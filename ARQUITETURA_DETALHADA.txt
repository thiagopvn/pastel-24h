VISÃO GERAL:
Este é um sistema completo de gestão de turnos para restaurantes, desenvolvido com Node.js/Express no backend e React/TypeScript no frontend. O sistema permite controle de turnos de trabalho, gestão de produtos, colaboradores, vendas, pagamentos e relatórios de folha de pagamento.

Esta é o coração do backend - servidor Express.js com TypeScript.

📄 ARQUIVOS PRINCIPAIS:
---------------------

server/index.ts
- Ponto de entrada principal do servidor
- Configura Express, middleware, rotas
- Inicia servidor HTTP e WebSocket
- Configuração de CORS e sessões

server/prod.ts
- Configuração específica para produção
- Serve arquivos estáticos compilados

server/vite.ts
- Configuração para desenvolvimento com Vite
- Hot-reload e proxy para desenvolvimento

server/auth.ts
- Sistema de autenticação com Passport.js
- Estratégia local com bcrypt para senhas
- Middleware de autorização (requireAuth, requireAdmin)
- Deserialização de usuários das sessões
- Hash de senhas com 12 rounds de bcrypt

server/routes.ts
- TODAS as rotas da API REST
- Endpoints organizados por funcionalidade:
  * /api/auth (login, logout, registro)
  * /api/products (CRUD de produtos)
  * /api/shifts/* (gestão de turnos)
  * /api/users (gestão de usuários)
  * /api/admin/* (funcionalidades administrativas)
- Validação com Zod schemas
- Tratamento de erros robusto

server/storage.ts
- Camada de abstração para operações do banco
- Funções de CRUD para todas as entidades
- Operações complexas (cálculos, relatórios)
- Gerenciamento de transações

server/db.ts
- Configuração da conexão com SQLite
- Inicialização do Drizzle ORM
- Setup da base de dados

server/ws.ts
- Servidor WebSocket para updates em tempo real
- Notificações de mudanças em turnos
- Comunicação bidirecional cliente-servidor

server/utils.ts
- Funções utilitárias para o servidor
- Helpers de formatação e validação

server/migrate.ts
- Sistema de migrações do banco de dados
- Executa automaticamente na inicialização

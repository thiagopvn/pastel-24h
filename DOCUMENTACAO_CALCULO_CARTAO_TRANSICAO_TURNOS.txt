# DOCUMENTAÇÃO DETALHADA - CÁLCULO DE CARTÃO DE CRÉDITO NA TRANSIÇÃO ENTRE TURNOS

## VISÃO GERAL DO SISTEMA

O sistema Pastel24h implementa uma lógica sofisticada para calcular valores de cartão de crédito durante as transições entre turnos. Esta lógica diferencia entre **valores cumulativos** (totais mostrados nas maquininhas) e **valores reais** (vendas efetivas do turno atual) para três métodos de pagamento:

- **Stone Card** (cartão de crédito)
- **Stone Voucher** (vale refeição)
- **PagBank Card** (processador de pagamento)

### Diferença Conceitual dos Campos

**Valores Cumulativos:**
- Representam o total mostrado no visor da maquininha
- Acumulam durante todo o dia, nunca zerados
- Inseridos manualmente pelo funcionário

**Valores Reais:**
- Representam as vendas efetivas do turno atual
- Calculados automaticamente pelo sistema
- Usados para relatórios e cálculos de receita

## CALCULADORA DE PAGAMENTOS COM CARTÃO

### Classe Principal: `CardPaymentCalculator`

```typescript
// server/lib/card-payment-calculator.ts
export class CardPaymentCalculator {
  constructor(private db: any) {}

  async calculateRealCardPayments(
    shiftId: number,
    cumulativeValues: CumulativeCardValues
  ): Promise<CardCalculationResult> {

    // 1. Verificar se é o primeiro turno do dia
    const isFirstShiftOfDay = await this.isFirstShiftOfDay(shiftId);

    if (isFirstShiftOfDay) {
      // Se for o primeiro turno: cumulative = real
      return {
        realValues: {
          stoneCard: parseFloat(cumulativeValues.stoneCardCumulative || '0'),
          stoneVoucher: parseFloat(cumulativeValues.stoneVoucherCumulative || '0'),
          pagBankCard: parseFloat(cumulativeValues.pagBankCardCumulative || '0')
        },
        previousAccumulated: { stoneCard: 0, stoneVoucher: 0, pagBankCard: 0 }
      };
    }

    // 2. Calcular acumulado anterior
    const previousAccumulated = await this.getPreviousAccumulated(shiftId);

    // 3. Calcular valores reais = cumulative atual - acumulado anterior
    const realValues = {
      stoneCard: Math.max(0,
        parseFloat(cumulativeValues.stoneCardCumulative || '0') - previousAccumulated.stoneCard
      ),
      stoneVoucher: Math.max(0,
        parseFloat(cumulativeValues.stoneVoucherCumulative || '0') - previousAccumulated.stoneVoucher
      ),
      pagBankCard: Math.max(0,
        parseFloat(cumulativeValues.pagBankCardCumulative || '0') - previousAccumulated.pagBankCard
      )
    };

    return { realValues, previousAccumulated };
  }
}
```

### Método: Verificação do Primeiro Turno do Dia

```typescript
private async isFirstShiftOfDay(shiftId: number): Promise<boolean> {
  const currentShift = await this.db.query.shifts.findFirst({
    where: eq(shifts.id, shiftId)
  });

  if (!currentShift) return false;

  const startOfDay = new Date(currentShift.startTime);
  startOfDay.setHours(0, 0, 0, 0);

  // Buscar turnos fechados desde o início do dia
  const previousShiftsToday = await this.db.query.shifts.findMany({
    where: and(
      gte(shifts.startTime, startOfDay.toISOString()),
      lt(shifts.id, shiftId),
      eq(shifts.status, 'closed')
    ),
    orderBy: [desc(shifts.id)]
  });

  // Se não há turnos fechados hoje, é o primeiro
  return previousShiftsToday.length === 0;
}
```

### Método: Cálculo do Acumulado Anterior

```typescript
private async getPreviousAccumulated(shiftId: number): Promise<AccumulatedValues> {
  const currentShift = await this.db.query.shifts.findFirst({
    where: eq(shifts.id, shiftId)
  });

  const startOfDay = new Date(currentShift.startTime);
  startOfDay.setHours(0, 0, 0, 0);

  // Buscar todos os turnos fechados desde o início do dia
  const previousShifts = await this.db.query.shifts.findMany({
    where: and(
      gte(shifts.startTime, startOfDay.toISOString()),
      lt(shifts.id, shiftId),
      eq(shifts.status, 'closed')
    ),
    with: { payments: true },
    orderBy: [asc(shifts.id)]
  });

  // Somar todos os valores reais dos turnos anteriores
  let accumulated = { stoneCard: 0, stoneVoucher: 0, pagBankCard: 0 };

  previousShifts.forEach(shift => {
    if (shift.payments) {
      accumulated.stoneCard += parseFloat(shift.payments.stoneCard || '0');
      accumulated.stoneVoucher += parseFloat(shift.payments.stoneVoucher || '0');
      accumulated.pagBankCard += parseFloat(shift.payments.pagBankCard || '0');
    }
  });

  return accumulated;
}
```

## FLUXO COMPLETO DE TRANSIÇÃO ENTRE TURNOS

### 1. FECHAMENTO DO TURNO ANTERIOR

```typescript
// server/routes.ts - Endpoint de fechamento
app.post('/api/shifts/:id/close', requireAuth, async (req, res) => {
  const { payments, cumulativeCardValues } = req.body;

  let finalPayments = payments;

  // Se valores cumulativos foram fornecidos, calcular valores reais
  if (cumulativeCardValues) {
    const cardCalculator = new CardPaymentCalculator(db);
    const calculatedCards = await cardCalculator.calculateRealCardPayments(
      shiftId,
      { ...payments, ...cumulativeCardValues }
    );

    // Combinar: PIX/Dinheiro originais + Cartões calculados
    finalPayments = {
      cash: payments.cash,                    // Mantém original
      pix: payments.pix,                      // Mantém original
      stoneCard: calculatedCards.realValues.stoneCard.toFixed(2),
      stoneVoucher: calculatedCards.realValues.stoneVoucher.toFixed(2),
      pagBankCard: calculatedCards.realValues.pagBankCard.toFixed(2)
    };

    // Salvar valores cumulativos também
    await db.update(shiftPayments)
      .set({
        ...finalPayments,
        stoneCardCumulative: cumulativeCardValues.stoneCardCumulative,
        stoneVoucherCumulative: cumulativeCardValues.stoneVoucherCumulative,
        pagBankCardCumulative: cumulativeCardValues.pagBankCardCumulative,
        calculatedFromCumulative: true
      })
      .where(eq(shiftPayments.shiftId, shiftId));
  }

  // Cálculo de herança de dinheiro para próximo turno
  const actualCash = parseFloat(req.body.finalCash) || 0;
  const actualCoins = parseFloat(req.body.finalCoins) || 0;
  const envelopeCash = parseFloat(req.body.envelopeCash) || 0;
  const envelopeCoins = parseFloat(req.body.envelopeCoins) || 0;

  const cashForNext = actualCash - envelopeCash;
  const coinsForNext = actualCoins - envelopeCoins;

  // Atualizar turno com valores finais
  await db.update(shifts).set({
    status: 'closed',
    endTime: new Date().toISOString(),
    finalCash: actualCash.toFixed(2),
    finalCoins: actualCoins.toFixed(2),
    cashForNextShift: cashForNext.toFixed(2),
    coinsForNextShift: coinsForNext.toFixed(2),
    // ... outros campos
  }).where(eq(shifts.id, shiftId));
});
```

### 2. ABERTURA DO NOVO TURNO

```typescript
// server/routes.ts - Endpoint de abertura
app.post('/api/shifts', requireAuth, async (req, res) => {
  // Buscar último turno fechado para herança
  const lastClosedShift = await db.query.shifts.findFirst({
    where: eq(shifts.status, 'closed'),
    orderBy: [desc(shifts.id)],
    with: { records: { with: { product: true } } }
  });

  // Cálculo de herança de dinheiro
  let expectedCash = "200.00";  // Padrão
  let expectedCoins = "50.00";

  if (lastClosedShift) {
    expectedCash = lastClosedShift.cashForNextShift || lastClosedShift.finalCash || "200.00";
    expectedCoins = lastClosedShift.coinsForNextShift || lastClosedShift.finalCoins || "50.00";
  }

  const informedCash = parseFloat(req.body.initialCash) || 0;
  const informedCoins = parseFloat(req.body.initialCoins) || 0;
  const expectedTotal = parseFloat(expectedCash) + parseFloat(expectedCoins);
  const informedTotal = informedCash + informedCoins;

  // Cálculo de divergência na abertura
  const openingDiscrepancy = informedTotal - expectedTotal;

  // Criar novo turno
  const [newShift] = await db.insert(shifts).values({
    userId: req.user.id,
    startTime: new Date().toISOString(),
    initialCash: informedCash.toFixed(2),
    initialCoins: informedCoins.toFixed(2),
    expectedCash: expectedCash,
    expectedCoins: expectedCoins,
    openingDiscrepancy: openingDiscrepancy.toFixed(2),
    status: 'open'
  }).returning();

  // Herança de produtos (sobras do turno anterior)
  if (lastClosedShift?.records) {
    const inheritanceRecords = lastClosedShift.records
      .filter(record => parseFloat(record.leftoverQty || '0') > 0)
      .map(record => ({
        shiftId: newShift.id,
        productId: record.productId,
        entryQty: record.leftoverQty,  // Sobra vira entrada
        arrivalQty: "0",
        discardQty: "0",
        consumptionQty: "0",
        leftoverQty: record.leftoverQty
      }));

    if (inheritanceRecords.length > 0) {
      await db.insert(shiftRecords).values(inheritanceRecords);
    }
  }
});
```

app.post('/api/shifts/:id/calculate-card-payments', requireAuth, async (req, res) => {
  const shiftId = parseInt(req.params.id);

### Adição dos Campos Cumulativos

```sql
-- migrations/0004_add_cumulative_card_fields.sql

-- Adicionar campos cumulativos para cada tipo de cartão
ALTER TABLE shift_payments ADD COLUMN stone_card_cumulative TEXT DEFAULT '0';
ALTER TABLE shift_payments ADD COLUMN stone_voucher_cumulative TEXT DEFAULT '0';
ALTER TABLE shift_payments ADD COLUMN pagbank_card_cumulative TEXT DEFAULT '0';

-- Adicionar flag de cálculo automático
ALTER TABLE shift_payments ADD COLUMN calculated_from_cumulative BOOLEAN DEFAULT false;

-- Migrar dados existentes: cumulative = real para registros antigos
UPDATE shift_payments
SET stone_card_cumulative = COALESCE(stone_card, '0')
WHERE stone_card_cumulative IS NULL OR stone_card_cumulative = '0';

UPDATE shift_payments
SET stone_voucher_cumulative = COALESCE(stone_voucher, '0')
WHERE stone_voucher_cumulative IS NULL OR stone_voucher_cumulative = '0';

UPDATE shift_payments
SET pagbank_card_cumulative = COALESCE(pagbank_card, '0')
WHERE pagbank_card_cumulative IS NULL OR pagbank_card_cumulative = '0';

-- Criar índices para performance
CREATE INDEX idx_shifts_start_time_status ON shifts(start_time, status);
CREATE INDEX idx_shift_payments_shift_id ON shift_payments(shift_id);
```

## CONSIDERAÇÕES IMPORTANTES

### Por que Dois Valores?

1. **Valor Cumulativo**: Reflete exatamente o que aparece na maquininha, permitindo auditoria
2. **Valor Real**: Usado para cálculos de receita e relatórios do turno específico
3. **Rastreabilidade**: Histórico completo de como os valores foram calculados

### Diferença para Dinheiro e PIX

- **Dinheiro**: Valor físico, sem acumulação entre turnos
- **PIX**: Transferência individual, sem acumulação
- **Cartões**: Maquininhas acumulam valores durante o dia inteiro

### Vantagens do Sistema

1. **Precisão**: Elimina erros de cálculo manual
2. **Auditoria**: Rastreabilidade completa dos valores
3. **Flexibilidade**: Suporta diferentes cenários operacionais
4. **Automação**: Reduz trabalho manual dos funcionários
5. **Consistência**: Garante cálculos uniformes entre turnos

Esta documentação apresenta o sistema completo de cálculo de cartão de crédito durante transições de turno, uma solução robusta que garante precisão financeira e facilita a operação diária do restaurante.

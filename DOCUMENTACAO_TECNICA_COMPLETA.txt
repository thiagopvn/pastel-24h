1. VISÃO GERAL DO SISTEMA
================================================================================

O Pastel24H é um sistema completo de gerenciamento de turnos para restaurante,
desenvolvido com arquitetura full-stack moderna para deployment local.

TECNOLOGIAS PRINCIPAIS:
------------------------
• Backend: Express.js + TypeScript + SQLite
• Frontend: React 18 + TypeScript + Vite
• Database: SQLite com Drizzle ORM
• Real-time: WebSocket para atualizações ao vivo
• UI: Shadcn/ui + Tailwind CSS + Framer Motion
• Autenticação: Passport.js com sessões
• Deploy: Docker com docker-compose

CARACTERÍSTICAS PRINCIPAIS:
---------------------------
• Controle de turnos com gestão de caixa completa
• Sistema de inventário com fórmula específica do negócio
• Múltiplos métodos de pagamento com taxas configuráveis
• Correções administrativas pós-fechamento
• Relatórios PDF e Excel automáticos
• Monitoramento em tempo real via WebSocket
• Sistema de permissões (admin/funcionário)

4. LÓGICA DE FECHAMENTO DE CAIXA (DETALHADO)
================================================================================

O fechamento de caixa é um processo crítico que ocorre em 3 etapas principais:

ETAPA 1: CONTAGEM FÍSICA DO CAIXA
----------------------------------
Local: /client/src/components/employee/close-shift-modal.tsx

1. Funcionário conta TODO o dinheiro físico na loja:
   - Separa NOTAS (cédulas de papel)
   - Separa MOEDAS (moedas metálicas)
   - Registra cada valor separadamente

2. Sistema carrega automaticamente valores salvos anteriormente:
   ```typescript
   // Busca valores temporários salvos no CashRegister
   const { tempFinalCash, tempFinalCoins } = await api.get('/api/shifts/temp-cash');
   setFinalCash(tempFinalCash || 0);
   setFinalCoins(tempFinalCoins || 0);
   ```

ETAPA 2: ENVELOPE ADMINISTRATIVO
---------------------------------
1. Define quanto do dinheiro contado vai para o envelope:
   - Valor em notas para envelope
   - Valor em moedas para envelope

2. Cálculo automático do que sobra para próximo turno:
   ```typescript
   cashForNextShift = finalCash - cashToEnvelope;
   coinsForNextShift = finalCoins - coinsToEnvelope;
   ```

ETAPA 3: CÁLCULO DE DIVERGÊNCIA
--------------------------------
Fórmula Principal:
```typescript
// De /client/src/lib/calculations.ts
function calculateCashDivergence(shift) {
  const initialCash = shift.initialCash + shift.initialCoins;
  const cashSales = shift.payments.cash;
  const withdrawals = shift.cashAdjustments
    .filter(a => a.type === 'withdraw')
    .reduce((sum, a) => sum + a.amount, 0);

  const expectedCash = initialCash + cashSales - withdrawals;
  const countedCash = shift.finalCash + shift.finalCoins;

  return countedCash - expectedCash;
}
```

VALIDAÇÕES DE DIVERGÊNCIA:
---------------------------
• Divergência Aceitável: até R$ 0,99 (MAX_CASH_DIVERGENCE)
• Divergência Crítica: > R$ 0,99 exige observações
• Verificação de Vendas: compara total produtos vs pagamentos

PROCESSO DE FECHAMENTO FINAL:
------------------------------
1. Validação de todos os campos obrigatórios
2. Cálculo de divergências e validações
3. Geração do snapshot do turno
4. Criação do PDF com todos os dados
5. Atualização do status para 'closed'
6. Notificação WebSocket para admin
7. Limpeza de dados temporários

5. FORMAS DE PAGAMENTO E CÁLCULOS
================================================================================

MÉTODOS DE PAGAMENTO DISPONÍVEIS:
----------------------------------
1. DINHEIRO
   - Sem taxa de transação
   - Afeta diretamente o caixa físico
   - Incluído no cálculo de divergência

2. PIX
   - Taxa configurável (padrão: 0%)
   - Processamento instantâneo
   - Não afeta caixa físico

3. STONE DÉBITO/CRÉDITO
   - Taxa padrão: 3.50%
   - Sistema de valor cumulativo na maquininha
   - Cálculo: Valor Real = Acumulado Atual - Acumulado Anterior

4. STONE VOUCHER (Vale Refeição/Alimentação)
   - Taxa padrão: 2.50%
   - Sistema de valor cumulativo
   - Separado do Stone D/C

5. PAGBANK DÉBITO/CRÉDITO
   - Taxa padrão: 3.20%
   - Sistema de valor cumulativo
   - Maquininha independente

SISTEMA DE VALORES CUMULATIVOS:
--------------------------------
Local: /server/lib/card-payment-calculator.ts

As maquininhas de cartão mantém um valor total acumulado do dia.
Para calcular o valor real do turno:

```typescript
export async function calculateCardPayments(shiftId, cumulativeValues) {
  // Busca o turno anterior do mesmo dia
  const previousShift = await getPreviousShiftSameDay(shiftId);

  // Calcula valores reais subtraindo o acumulado anterior
  const realValues = {
    stoneCard: cumulativeValues.stoneCard -
               (previousShift?.stoneCardCumulative || 0),

    stoneVoucher: cumulativeValues.stoneVoucher -
                  (previousShift?.stoneVoucherCumulative || 0),

    pagBankCard: cumulativeValues.pagBankCard -
                 (previousShift?.pagBankCardCumulative || 0)
  };

  return realValues;
}
```

CÁLCULO DE VALORES LÍQUIDOS:
-----------------------------
```typescript
// De /client/src/lib/constants.ts
const PAYMENT_RATES = {
  pix: 0,          // 0% de taxa
  stoneCard: 0.035,     // 3.5% de taxa
  stoneVoucher: 0.025,  // 2.5% de taxa
  pagBankCard: 0.032    // 3.2% de taxa
};

// Cálculo do valor líquido
function calculateNetValue(grossValue, paymentMethod) {
  const rate = PAYMENT_RATES[paymentMethod];
  const fee = grossValue * rate;
  return grossValue - fee;
}
```

PROCESSO DE REGISTRO DE PAGAMENTOS:
------------------------------------
1. Funcionário registra valores no CashRegister.tsx
2. Para maquininhas: informa valor cumulativo total
3. Sistema calcula automaticamente valor real do turno
4. Salva no banco: valores reais E cumulativos
5. Admin pode corrigir posteriormente se necessário

EXEMPLO PRÁTICO DE CÁLCULO:
----------------------------
Cenário: Stone D/C mostra R$ 1.500,00 no visor

1. Turno anterior terminou com R$ 850,00 acumulado
2. Valor real deste turno = R$ 1.500,00 - R$ 850,00 = R$ 650,00
3. Taxa de 3.5%: Fee = R$ 650,00 × 0.035 = R$ 22,75
4. Valor líquido = R$ 650,00 - R$ 22,75 = R$ 627,25

```typescript
// Servidor WebSocket
wss.on('connection', (ws, req) => {
  const shiftId = parseShiftId(req.url);

  // Cliente se conecta a um turno específico
  if (!shiftConnections.has(shiftId)) {
    shiftConnections.set(shiftId, new Set());
  }
  shiftConnections.get(shiftId).add(ws);

  // Notifica mudanças
  ws.on('shift-update', () => {
    notifyShiftClients(shiftId);
  });
});

// Função para notificar todos os clientes
export function notifyShiftClients(shiftId: number) {
  const clients = shiftConnections.get(shiftId);
  clients?.forEach(client => {
    client.send(JSON.stringify({
      type: 'shift-updated',
      shiftId
    }));
  });
}
```

EXEMPLO 2: CÁLCULO DE DIVERGÊNCIA
----------------------------------
```typescript
// Backend - /server/lib/shift-processor-sql.ts
function calculateDivergence(shift: ProcessedShift): number {
  const initialTotal =
    parseFloat(shift.initialCash) +
    parseFloat(shift.initialCoins);

  const cashSales = parseFloat(shift.payments?.cash || '0');

  const withdrawals = shift.cashAdjustments
    ?.filter(adj => adj.type === 'withdraw')
    ?.reduce((sum, adj) => sum + parseFloat(adj.amount), 0) || 0;

  const expectedTotal = initialTotal + cashSales - withdrawals;

  const countedTotal =
    parseFloat(shift.finalCash || '0') +
    parseFloat(shift.finalCoins || '0');

  return countedTotal - expectedTotal;
}
```

EXEMPLO 6: FÓRMULA DE INVENTÁRIO
---------------------------------
```typescript
// Frontend - /client/src/lib/calculations.ts
export function calculateSoldQuantity(record: ShiftRecord): number {
  const entry = parseInt(record.entryQty) || 0;
  const arrival = parseInt(record.arrivalQty) || 0;
  const leftover = parseInt(record.leftoverQty) || 0;
  const discard = parseInt(record.discardQty) || 0;
  const consumed = parseInt(record.consumedQty) || 0;

  // Fórmula principal do negócio
  const sold = entry + arrival - leftover - discard - consumed;

  return Math.max(0, sold); // Nunca negativo
}
```

```typescript
// Configuração da estratégia local
passport.use(new LocalStrategy(
  { usernameField: 'email' },
  async (email, password, done) => {
    const user = await findUserByEmail(email);

    if (!user) {
      return done(null, false, { message: 'Usuário não encontrado' });
    }

    const isValid = await bcrypt.compare(password, user.password);

    if (!isValid) {
      return done(null, false, { message: 'Senha incorreta' });
    }

    return done(null, user);
  }
));

// Sessão com memorystore
app.use(session({
  secret: process.env.SESSION_SECRET,
  resave: false,
  saveUninitialized: false,
  cookie: {
    secure: process.env.NODE_ENV === 'production',
    httpOnly: true,
    maxAge: 24 * 60 * 60 * 1000 // 24 horas
  },
  store: new MemoryStore({
    checkPeriod: 86400000 // Limpa sessões expiradas diariamente
  })
}));
```

```typescript
const requireAdmin = (req, res, next) => {
  if (!req.isAuthenticated()) {
    return res.status(401).json({
      message: "Authentication required"
    });
  }

  if (req.user.role !== 'admin') {
    return res.status(403).json({
      message: "Admin access required"
    });
  }

  next();
};
```

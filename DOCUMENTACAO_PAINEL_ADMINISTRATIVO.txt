## 1. VISÃO GERAL DO PAINEL ADMINISTRATIVO

O painel administrativo do Pastel24h é uma interface completa de gestão empresarial que permite controle total sobre operações, funcionários, produtos, finanças e relatórios.

### Principais Características:
- **Interface Responsiva**: Adaptável para desktop e mobile
- **Autenticação Segura**: Controle de acesso baseado em roles
- **Tempo Real**: Atualizações automáticas via WebSocket
- **Auditoria Completa**: Rastreamento de todas as ações
- **Exportação de Dados**: PDF e Excel para relatórios

### Tecnologias Utilizadas:
- **Frontend**: React 18, TypeScript, Wouter, TanStack Query
- **UI Framework**: Shadcn/ui, Tailwind CSS, Framer Motion
- **Backend**: Express.js, SQLite, Drizzle ORM, Passport.js
- **Real-time**: WebSocket para atualizações em tempo real
- **Visualização**: Recharts para gráficos e dashboard

## 2. ROTAS E NAVEGAÇÃO

### Estrutura de Rotas (/App.tsx):
```
/admin                              - Dashboard Principal
/admin/products                     - Gestão de Produtos
/admin/users                        - Gestão de Usuários
```

## 12. BACKEND E SEGURANÇA

### 12.1 Middleware de Autenticação (routes.ts):
```typescript
// Middleware para verificar autenticação
const requireAuth = (req, res, next) => {
  if (!req.isAuthenticated()) {
    return res.status(401).json({ message: "Authentication required" });
  }
  next();
};

// Middleware para verificar papel de admin
const requireAdmin = (req, res, next) => {
  if (!req.isAuthenticated() || req.user.role !== 'admin') {
    return res.status(403).json({ message: "Admin access required" });
  }
  next();
};
```

### 12.2 Rotas Protegidas:
- **Todas as rotas admin**: Requerem `requireAdmin`
- **Validação de Dados**: Schemas Zod para todos os endpoints
- **Tratamento de Erros**: Responses padronizados
- **Logging**: Registro de todas as ações administrativas
